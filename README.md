# Lançamento Nike Air

## Sobre o projeto

A página apresenta uma chamada de lançamento dividida em dois blocos: uma área textual com o conceito do produto e uma área visual com o tênis em destaque. O layout foi pensado para transmitir a ideia de inovação e movimento associada ao slogan “O tênis do futuro”.

## Características

- Layout responsivo para diferentes tamanhos de tela.
- Composição em duas colunas no desktop e empilhada em telas menores.
- Destaque visual para o Nike Air com imagem de produto.
- Interações de hover no título, botão e imagem do tênis.
- Animações e estilos aplicados diretamente com classes utilitárias.
- Interface limpa, com alto contraste e foco na hierarquia do conteúdo.

## Tecnologias

- HTML5
- Tailwind CSS 4 via CDN
- Google Fonts, com a família tipográfica Poppins
- CSS customizado para tema, imagem de fundo e animações

## Direção visual

O projeto combina uma base clara e neutra com uma área de produto em fundo azul acinzentado. A fonte Poppins reforça o aspecto contemporâneo da página, enquanto as transições de escala e rotação adicionam sensação de movimento ao tênis e aos elementos de interação.
